Як користуватися цим документом

  • Не вчи тексти напам'ять — вчи СХЕМУ. Тексти потрібні лише як зразок наповнення.
  • Бери 2–3 фрази з кожного блоку Redemittel і доводь їх до автоматизму.
  • Універсальна схема Forumsbeitrag: Anrede → Einleitung → Meinung → Beispiel → Gegenseite → Vorschlag → Frage → Gruß.
  • Універсальна схема Beschwerde: Anrede → Dank → Bedauern → Grund → Lösung → Garantie → Schluss.

I. SPRECHEN

1. Teil 1 — Präsentation

Монолог на задану тему. Оцінюють структуру, зв'язність, лексику рівня B2 і здатність відповісти на 1–2 запитання після виступу.

1.1 Redemittel: Arbeitgeber

  • Ich möchte über einen interessanten Arbeitgeber sprechen, für den ich gearbeitet habe / bei dem ich gern arbeiten würde.
  • Die Firma heißt … und ist im Bereich … tätig.
  • Sie wurde im Jahr … von … gegründet.
  • Das Unternehmen hat … Mitarbeiter.
  • Die Firma verkauft / produziert / berät / hilft …
  • Die Firma hat verschiedene Filialen in Deutschland / Europa / auf der ganzen Welt.
  • Die Firma ist in Deutschland / international bekannt.
  • Es gibt verschiedene Abteilungen / Bereiche in der Firma, z. B. …
  • Der Chef ist … / Die Kollegen sind …
  • Die Firma ist ein guter Arbeitgeber, weil …
  • Die Firma hat einen guten Ruf, weil …
  • Ich habe gern bei der Firma gearbeitet, weil …
  • Ich würde gern bei der Firma arbeiten, weil …

1.2 Redemittel: Gutes Arbeitsumfeld

  • Ich möchte darüber sprechen, was für mich ein gutes Arbeitsumfeld bedeutet.
  • Am wichtigsten finde ich …
  • Mir ist wichtig, dass die Kollegen … / der Chef … sind.
  • Das Gehalt sollte … sein.
  • Ich lege großen Wert darauf, dass …
  • Ich wünsche mir, dass …
  • Am besten arbeiten kann ich, wenn es … gibt.
  • Ich fühle mich wohl, wenn ich … habe.
  • Ich gehe gerne zur Arbeit, wenn …
  • Ich bin zufrieden, wenn …
  • Ich mag es nicht, wenn …
  • Außerdem finde ich wichtig, dass …

1.3 Redemittel: Berufswahl

  • Ich möchte über die Gründe für meine Berufswahl sprechen.
  • Mein Beruf ist … / Ich würde gerne als … arbeiten.
  • Ich habe mich für diesen Beruf entschieden, weil …
  • Schon als Kind wollte ich … / habe ich gern …
  • Ich habe … Jahre in diesem Beruf gearbeitet.
  • Ich finde diesen Beruf sehr interessant, weil …
  • In diesem Beruf kann man … / muss man …
  • Außerdem gefällt mir an dem Beruf, dass man …

1.4 Redemittel: Berufliches Vorbild

  • Mein berufliches Vorbild ist meine Mutter / mein bester Freund / mein Chef.
  • Er/Sie ist mein berufliches Vorbild, weil …
  • Ich schätze an ihm/ihr, dass er/sie immer … ist.
  • Ich wäre auch gern so fleißig / ehrgeizig / zielstrebig wie er/sie.
  • … hat mich in meinem Leben sehr inspiriert, weil …
  • Ich kann von ihm/ihr viel lernen, weil …
  • Er/Sie hat viel Erfahrung und ist ein intelligenter / kreativer / ehrgeiziger Mensch.
  • Er/Sie kann gut Probleme lösen / mit Kunden sprechen / mit Kindern umgehen.

1.5 Redemittel: Vorgehen bei der Arbeitssuche

  • Ich möchte darüber sprechen, wie man in … Arbeit finden kann.
  • Es gibt verschiedene Möglichkeiten, wie man einen guten Job finden kann.
  • Zum Beispiel kann man in der Zeitung / im Internet nach Stellenangeboten suchen.
  • Außerdem kann man …
  • Eine andere Möglichkeit ist, dass man …
  • Es ist wichtig, dass man …
  • Man kann auch versuchen, … zu …
  • … spielt / spielen eine wichtige Rolle bei der Arbeitssuche.

1.6 Redemittel: Bewerbungsgespräch

  • Ich möchte darüber sprechen, was bei einem Vorstellungsgespräch in … wichtig ist.
  • Zunächst sollte man darauf achten, dass man …
  • Außerdem ist wichtig, dass man …
  • Man sollte sich gut auf ein Vorstellungsgespräch vorbereiten. Zum Beispiel sollte man …
  • Die Kleidung sollte … sein.
  • Man muss Motivation zeigen / Blickkontakt halten / immer höflich bleiben.
  • Am Ende des Gesprächs sollte man …
  • Auf keinen Fall darf man …

1.7 Redemittel: Produkt

  • Ich möchte über ein Produkt sprechen, das ich interessant finde / das ich mir gekauft habe.
  • Es ist ein/e … von der Firma … und kostet … Euro.
  • Man kann das Produkt online / im Elektrofachgeschäft / im Supermarkt kaufen.
  • Man kann damit telefonieren / Fotos machen / Filme schauen.
  • Ich habe … kürzlich gekauft und bin sehr zufrieden damit.
  • … hat gute Qualität / ist leistungsfähig / ist sehr praktisch / nützlich.
  • Ich kann … jedem empfehlen, weil …
  • Der größte Vorteil von … ist, dass …
  • Ein Nachteil ist, dass …

1.8 Redemittel: Selbstständigkeit

  • Ich möchte eine interessante Geschäftsidee präsentieren.
  • Ich würde gern eine Firma gründen / ein Restaurant eröffnen / ein Geschäft eröffnen.
  • In dieser Firma / In diesem Restaurant / In diesem Geschäft würde ich … verkaufen / anbieten.
  • Ich habe viele Ideen. Zum Beispiel möchte ich …
  • Zu meiner Zielgruppe gehören Kinder / Erwachsene / ältere Menschen / Ausländer.
  • In meiner Firma / meinem Restaurant / meinem Geschäft würde es … geben.
  • Das Besondere an meiner Firma / meinem Restaurant / meinem Geschäft wäre, dass man …

2. Universelle Redemittel für die Präsentation (50 Phrasen)

2.1 Anfang des Monologs

  • Ich möchte Ihnen heute das Thema … vorstellen.  —  Я хотел(а) бы сегодня представить Вам тему…
  • Mein Vortrag gliedert sich in drei Teile.  —  Мой доклад состоит из трёх частей.
  • Zuerst spreche ich über …, dann über …, und am Ende fasse ich zusammen.  —  Сначала расскажу о…, затем о…, в конце подведу итог.
  • Ich beginne mit einem kurzen Überblick.  —  Начну с краткого обзора.
  • Lassen Sie mich mit einer wichtigen Frage beginnen.  —  Позвольте начать с важного вопроса.

2.2 Argumente DAFÜR

  • Ein wesentlicher Vorteil ist, dass …  —  Существенное преимущество состоит в том, что…
  • Außerdem spricht dafür, dass …  —  Кроме того, в пользу этого говорит то, что…
  • Ein weiterer positiver Aspekt ist …  —  Ещё один положительный аспект — это…
  • Das hat den Vorteil, dass …  —  Это имеет преимущество в том, что…
  • Besonders wichtig erscheint mir, dass …  —  Особенно важным мне кажется то, что…
  • Hinzu kommt, dass …  —  К этому добавляется то, что…

2.3 Argumente DAGEGEN

  • Andererseits muss man bedenken, dass …  —  С другой стороны, нужно учитывать, что…
  • Ein Nachteil dabei ist, dass …  —  Недостаток здесь в том, что…
  • Allerdings gibt es auch Probleme: …  —  Однако есть и проблемы:…
  • Man darf nicht vergessen, dass …  —  Нельзя забывать о том, что…
  • Kritisch zu sehen ist, dass …  —  Критически следует оценить то, что…
  • Einerseits … andererseits …  —  С одной стороны… с другой стороны…

2.4 Meinung äußern

  • Meiner Meinung nach …  —  По моему мнению…
  • Ich bin der Ansicht, dass …  —  Я придерживаюсь мнения, что…
  • Ich halte es für wichtig, dass …  —  Я считаю важным то, что…
  • Persönlich finde ich, dass …  —  Лично я считаю, что…
  • Aus meiner Sicht …  —  С моей точки зрения…
  • Ich würde sagen, dass …  —  Я бы сказал(а), что…

2.5 Abschluss des Monologs

  • Zusammenfassend lässt sich sagen, dass …  —  Подводя итог, можно сказать, что…
  • Abschließend möchte ich betonen, dass …  —  В заключение хотел(а) бы подчеркнуть, что…
  • Ich komme zum Schluss meines Vortrags.  —  Я подхожу к концу своего выступления.
  • Vielen Dank für Ihre Aufmerksamkeit.  —  Большое спасибо за Ваше внимание.
  • Ich freue mich auf Ihre Fragen.  —  Жду Ваших вопросов.

3. Musterpräsentationen

Thema 1 — Ein Arbeitgeber, für den ich gearbeitet habe

Що писати: коротко хто ти за професією та де працював, кілька фактів про фірму — і головне: твої обов'язки та особливості роботи. Іноді екзаменатор хоче почути про роботодавця як про людину (начальника) — тоді опиши його якості та обов'язки.

Ich habe einige Jahre in einer internationalen Speditionsfirma gearbeitet. Das Unternehmen war im Bereich Transport und Logistik tätig und hatte viele Kunden in Europa.

Meine Abteilung war für die Buchhaltung zuständig. Dort habe ich Rechnungen erstellt, Zahlungen überwacht und Monatsabschlüsse vorbereitet.

Besonders interessant war die enge Zusammenarbeit mit den Kolleginnen aus anderen Abteilungen, zum Beispiel aus dem Vertrieb oder der Kundenbetreuung. Die Arbeit war abwechslungsreich, weil es immer wieder neue Situationen gab, etwa bei internationalen Zahlungen oder bei Verzögerungen im Transport.

Ich habe dort gelernt, flexibel zu sein und schnell auf Probleme zu reagieren. Außerdem habe ich meine Kenntnisse in moderner Software verbessert und mit internationalen Partnern auf Englisch kommuniziert.

Ein großer Vorteil dieser Firma war, dass sie regelmäßig interne Schulungen organisiert hat. So konnten wir uns ständig weiterentwickeln.

Zusammenfassend war es eine wertvolle Erfahrung, die mir nicht nur Fachwissen, sondern auch soziale Kompetenzen vermittelt hat.

Thema 2 — Mein gutes Arbeitsumfeld

Що писати: коротко про місце роботи, а далі — можливості кар'єрного росту, робоча атмосфера, як вирішували проблеми в команді, наскільки був задоволений роботою. Тему 1 і 2 можна поєднувати: у темі 1 акцент на завданнях, у темі 2 — на атмосфері.

Ein gutes Arbeitsumfeld bedeutet für mich vor allem, dass man sich im Team wohlfühlt.

Ich stelle mir vor, dass es eine offene Kommunikation gibt und man bei Problemen jederzeit mit Kollegen oder Vorgesetzten sprechen kann.

Wichtig sind auch faire Arbeitsbedingungen: ein sicherer Arbeitsplatz, ein geregeltes Einkommen und Chancen zur Weiterbildung.

Außerdem finde ich flexible Arbeitszeiten und Homeoffice-Möglichkeiten sehr wichtig, damit man Beruf und Privatleben besser verbinden kann.

Ein positives Arbeitsklima ist entscheidend, weil motivierte Mitarbeiter auch bessere Ergebnisse für die Firma bringen.

Aus meiner Erfahrung weiß ich: Wenn das Team gut zusammenarbeitet, macht die Arbeit mehr Spaß und man ist produktiver.

Ich halte es auch für wichtig, dass gute Leistungen anerkannt und belohnt werden, zum Beispiel durch Bonuszahlungen oder Lob vom Vorgesetzten.

Ein modernes Arbeitsumfeld sollte außerdem über digitale Tools verfügen, die die Arbeit erleichtern.

So entsteht eine Atmosphäre, in der man gerne arbeitet, motiviert bleibt und langfristig im Unternehmen bleiben möchte.

Thema 3 — Ereignisse, die meine Berufswahl beeinflusst haben

Що писати: ким хотів стати в дитинстві, які предмети цікавили, як прийшов до своєї професії. Загальний опис життєвого шляху до вибору професії.

Meine Berufswahl wurde stark durch meine Schulerfahrungen beeinflusst.

In der Schule hatte ich ein großes Interesse an Mathematik und Wirtschaft. Diese Fächer fielen mir leicht, und meine Lehrer haben mich immer unterstützt.

Ein wichtiger Moment war, als ich ein Schülerpraktikum in einer Bank gemacht habe. Dort konnte ich zum ersten Mal erleben, wie Zahlen und Finanzen im Alltag eine große Rolle spielen.

Das hat mein Interesse an Buchhaltung und Finanzwesen noch verstärkt.

Außerdem hat mich die Vorstellung motiviert, einen sicheren Beruf mit guten Perspektiven zu wählen.

Heute bin ich überzeugt, dass diese Entscheidung richtig war, weil ich in diesem Bereich meine Stärken einsetzen kann.

Ein weiterer Faktor war meine Begeisterung für genaues Arbeiten. Ich habe schon früh gemerkt, dass ich gerne strukturiert und ordentlich arbeite.

Auch meine Eltern haben mich immer unterstützt und mir geraten, einen Beruf mit Zukunft zu wählen.

Zusammenfassend war es eine Kombination aus schulischen Erfahrungen, familiärer Unterstützung und persönlicher Motivation, die meine Berufswahl geprägt hat.

Thema 4 — Mein berufliches Vorbild

Що писати: зазвичай про маму, тата, дідуся/бабусю або про начальника — хто працював у цій сфері, чому надихнув, чого навчив. Теми 3 і 4 можна поєднати.

Eine Person, die für mich ein berufliches Vorbild ist, ist meine ehemalige Chefin.

Sie war Leiterin der Buchhaltungsabteilung und hat viele Jahre Erfahrung gesammelt.

Was mich besonders beeindruckt hat, ist ihre Ruhe und Professionalität, auch in stressigen Situationen.

Sie konnte schwierige Probleme sachlich analysieren und schnell gute Lösungen finden.

Außerdem war sie sehr hilfsbereit und hat immer ihre Mitarbeiter unterstützt.

Unsere Beziehung war respektvoll und vertrauensvoll. Sie hat mir gezeigt, wie wichtig Teamarbeit ist und dass man immer fair bleiben soll.

Besonders bewundert habe ich ihre Genauigkeit: kein Dokument wurde abgegeben, ohne dass es hundertprozentig korrekt war.

Gleichzeitig konnte sie aber auch flexibel sein, wenn neue Aufgaben oder unerwartete Probleme aufgetreten sind.

Sie hat mir beigebracht, dass gute Führung bedeutet, Verantwortung zu übernehmen und Vorbild für andere zu sein.

Durch ihr Beispiel habe ich gelernt, dass man im Beruf nicht nur Fachwissen, sondern auch soziale Kompetenzen braucht.

Zusammenfassend hat sie mir gezeigt, dass man mit Geduld, Kompetenz und Respekt sehr viel erreichen kann.

Thema 5 — Vorgehen bei der Arbeitssuche in Deutschland

Що писати: способи пошуку роботи (платформи, знайомі, біржа праці), що вивчити перед відправкою резюме, які документи потрібні. Можна додати власний досвід.

In Deutschland gibt es verschiedene Wege, eine Arbeitsstelle zu finden.

Viele Menschen nutzen Online-Jobbörsen wie Stepstone oder Indeed. Dort kann man gezielt nach Stellen in bestimmten Branchen und Regionen suchen.

Sehr wichtig ist auch die offizielle Seite der Agentur für Arbeit, die viele Angebote veröffentlicht.

Ein weiterer Schritt ist das Bewerben direkt auf den Firmenwebseiten. Viele Unternehmen schreiben ihre Stellen dort zuerst aus.

Auch Zeitungen und Fachzeitschriften können manchmal interessante Angebote enthalten.

Wenn man passende Stellen gefunden hat, erstellt man eine Bewerbung mit Lebenslauf und Anschreiben. Diese Unterlagen sollten klar, strukturiert und fehlerfrei sein.

Danach folgt der Erstkontakt mit dem Arbeitgeber, meist per E-Mail oder über ein Online-Portal. Bei Interesse wird man zu einem Vorstellungsgespräch eingeladen.

In Deutschland spielt auch Networking eine große Rolle. Über persönliche Kontakte oder Plattformen wie LinkedIn kann man ebenfalls gute Chancen finden.

Wichtig ist außerdem, sich gut auf Bewerbungsgespräche vorzubereiten, um überzeugend aufzutreten.

Zusammenfassend lässt sich sagen, dass die Arbeitssuche in Deutschland ein klar strukturierter, aber manchmal auch zeitaufwändiger Prozess ist.

Thema 6 — Ein Bewerbungsgespräch in Deutschland

Що писати: кроки після запрошення — дізнатися більше про компанію, підготувати запитання, вдягнутися пристойно, прийти вчасно, і що буде після співбесіди. Теми 5 і 6 теж можна поєднати.

Ein Bewerbungsgespräch in Deutschland ist ein sehr wichtiger Teil des Auswahlprozesses.

Zuerst sollte man sich gründlich vorbereiten. Man muss sich über die Firma informieren und genau wissen, welche Aufgaben in der Stelle erwartet werden.

Ein gepflegtes und professionelles Erscheinungsbild ist selbstverständlich. Männer tragen meist Anzug und Krawatte, Frauen ein Kostüm oder einen Hosenanzug.

Sehr wichtig ist Pünktlichkeit: Man sollte mindestens zehn Minuten vor dem Termin erscheinen und genug Zeit für die Anreise einplanen.

Im Gespräch selbst kommt es auf Freundlichkeit, Höflichkeit und Selbstbewusstsein an. Ein fester Händedruck und Blickkontakt machen einen guten Eindruck.

Typische Fragen betreffen Stärken und Schwächen, Berufserfahrungen oder die Motivation für die Bewerbung.

Oft werden auch Fragen nach Teamarbeit, Konflikten oder zukünftigen Zielen gestellt. Man sollte klare und präzise Antworten geben und seine Eignung für die Stelle betonen.

Wichtig ist auch, eigene Fragen zu stellen, zum Beispiel zu den Aufgaben, zum Team oder zu Weiterbildungsmöglichkeiten.

Nach dem Gespräch empfiehlt es sich, sich per E-Mail für die Einladung zu bedanken. Das zeigt Interesse und Professionalität.

Wer gut vorbereitet, selbstbewusst und freundlich auftritt, kann einen sehr positiven Eindruck hinterlassen.

Thema 7 — Ein Produkt: Das Smartphone

Що писати: загальний опис продукту, для чого його використовують, плюси й мінуси, висновок. Це може бути будь-що: телефон, авто, планшет, свічки, страва.

Ich habe mich für das Thema Smartphone entschieden, weil es heute ein fester Bestandteil unseres Alltags ist. In den letzten zwanzig Jahren hat sich dieses Gerät von einem einfachen Telefon zu einem multifunktionalen Begleiter entwickelt.

Ein Smartphone bietet zahlreiche Funktionen: Telefonieren, Nachrichten schreiben, Fotografieren, Navigation und Online-Banking. Für viele Menschen ist es inzwischen unverzichtbar. Besonders praktisch ist die ständige Erreichbarkeit sowie der schnelle Zugriff auf Informationen.

Zu den Vorteilen gehört, dass man viele Geräte in einem vereint — Kamera, Kalender, Notizbuch und Computer. Das spart Platz und Zeit. Außerdem ermöglicht es uns, weltweit in Kontakt zu bleiben und auch unterwegs zu arbeiten.

Natürlich gibt es auch Nachteile. Smartphones können sehr teuer sein, besonders die neuesten Modelle. Außerdem besteht die Gefahr, dass man zu viel Zeit am Bildschirm verbringt und dadurch die persönliche Kommunikation leidet. Auch Datenschutz und Abhängigkeit sind problematische Themen.

Insgesamt lässt sich sagen, dass das Smartphone ein sehr erfolgreiches Produkt ist, das unsere Arbeitswelt und unser Privatleben stark verändert hat. Es bringt viele Vorteile, erfordert aber auch einen bewussten Umgang.

Vielen Dank für Ihre Aufmerksamkeit.

Thema 8 — Geschäftsidee: Sprachschule online

Що писати: який бізнес хотів би відкрити в Німеччині, для кого, чому, як би це працювало. Теми 7 і 8 можна поєднати: у 7 — товар/послуга, у 8 — його реалізація.

Ich möchte heute meine Geschäftsidee vorstellen: die Gründung einer Online-Sprachschule. Die Nachfrage nach Sprachkursen wächst ständig, besonders für Deutsch als Fremdsprache. Viele Menschen möchten flexibel von zu Hause aus lernen, und genau darauf basiert meine Idee.

Die Besonderheit meiner Schule wäre ein modular aufgebautes Kurssystem: Anfänger bis Fortgeschrittene können passende Pakete buchen. Zusätzlich biete ich spezielle Kurse an, zum Beispiel für den Beruf, für Prüfungen oder für den Alltag in Deutschland.

Ein weiterer wichtiger Punkt ist die Interaktivität. Neben Video-Unterricht sollen die Teilnehmenden auch Zugang zu digitalen Übungen, Apps und Online-Tests haben. Dadurch können sie ihren Lernfortschritt jederzeit überprüfen.

Natürlich gibt es auch Herausforderungen: Man braucht eine stabile technische Plattform und qualifizierte Lehrkräfte. Auch die Werbung und das Vertrauen neuer Kunden sind entscheidend für den Erfolg.

Meine Zielgruppe sind Erwachsene, die in Deutschland leben oder arbeiten möchten, sowie internationale Studierende und Fachkräfte. Sie brauchen praxisnahe und flexible Sprachkurse.

Zusammenfassend bietet meine Geschäftsidee die Möglichkeit, Bildung und Digitalisierung sinnvoll zu verbinden.

Vielen Dank für Ihre Aufmerksamkeit.

3.1 Mögliche Fragen der Prüfer nach der Präsentation

На екзамені можуть бути й інші — але логіка та сама: уточнення до твоєї теми та порівняння з рідною країною.
  • Welche Arbeitgeber hatten Sie?
  • Welche Pläne haben Sie für die Zukunft?
  • Haben Sie auch negative Beispiele in Ihrer Berufserfahrung?
  • Wie wichtig sind die Karrierechancen für Sie?
  • Welchen Beruf wollten Sie als Kind haben?
  • Welche Faktoren haben Sie beeinflusst, auf diesen Beruf zu verzichten?
  • Welche Unterschiede gibt es zwischen der Arbeitssuche in Ihrem Heimatland und in Deutschland?
  • Hatten Sie schon ein Bewerbungsgespräch in Deutschland?
  • Welche Fragen kann der Kandidat / Bewerber stellen?

5. Teil 3 — Lösungswege finden

Діалог із партнером: разом вирішуєте робочу проблему (скарги клієнтів, помилка в замовленні, конфлікт у команді). Обов'язково: назвати проблему → запропонувати рішення → домовитись про розподіл завдань → підсумувати.

  • Wir müssen mit dem Lieferanten / mit der Transportfirma / mit den Kollegen sprechen.
  • Wir müssen den Lieferanten / die Transportfirma wechseln.
  • Wir müssen den Vertrag mit dem Lieferanten / mit der Transportfirma kündigen.

  • Wir könnten eine Teambesprechung organisieren und das Problem mit den Kollegen / mit dem Chef besprechen. Vielleicht morgen / nächste Woche um … Uhr?
  • Wir müssen das Problem auf jeden Fall so schnell wie möglich lösen, damit wir unsere Kunden nicht verlieren.

5.5 Zustimmen und ablehnen

  • Ich stimme dir zu. Das ist eine gute Idee. Das machen wir so!
  • Ich stimme dir nicht zu. Das ist keine gute Idee. Ich habe einen besseren Vorschlag.

  • Damit bin ich einverstanden.  —  С этим я согласен(на).
  • Dem kann ich nur zustimmen.  —  Я могу только согласиться с этим.
  • Du hast / Sie haben recht, so machen wir es.  —  Ты прав / Вы правы, так и сделаем.
  • Das gefällt mir. Wir dürfen aber nicht vergessen, dass …  —  Мне это нравится. Но мы не должны забывать, что…
  • Das finde ich gut. Weiter finde ich wichtig, …  —  Мне это нравится. Далее, я считаю важным, …

5.6 Vorschläge und Kompromiss

  • Ich habe eine Idee / einen Vorschlag: …  —  У меня есть идея / предложение: …
  • Ich schlage vor, dass …  —  Я предлагаю, чтобы …
  • Mein Vorschlag wäre …  —  Моё предложение было бы …
  • Was hältst du / halten Sie davon, wenn wir …?  —  Что ты думаешь / Вы думаете о том, если мы…?
  • Wir könnten auch …  —  Мы могли бы также …
  • Dazu könnten wir noch …  —  К этому мы могли бы ещё …
  • Vielleicht wäre es besser, wenn …  —  Возможно, было бы лучше, если …
  • Ich finde es besser, wenn …  —  Я считаю, что будет лучше, если …
  • Wäre es möglich, …?  —  Было бы возможно…?
  • Wie wäre es, wenn …?  —  Как бы Вы отнеслись к тому, если бы…?
  • Könnten wir uns auf … einigen?  —  Могли бы мы договориться о…?
  • Als Kompromiss würde ich vorschlagen …  —  В качестве компромисса предложил(а) бы…
  • Das könnte eine Lösung sein.  —  Это могло бы быть решением.

5.7 Höflich widersprechen

  • Es tut mir leid, aber ich kann dir/Ihnen nicht zustimmen.  —  Простите, но я не могу с тобой/вами согласиться.
  • Da muss ich dir/Ihnen widersprechen.  —  Здесь я должен(а) тебе/вам возразить.
  • Besser wäre, wenn …  —  Лучше было бы, если …
  • Das finde ich nicht gut. Ich habe eine andere Idee: …  —  Мне это не нравится. У меня есть другая идея: …
  • Ich bin anderer Meinung. Wir sollten …  —  Я другого мнения. Нам следует …
  • Das kommt nicht infrage, so geht es nicht. Wir müssen auf jeden Fall zuerst …  —  Это исключено, так не пойдёт. Нам обязательно нужно сначала …
  • Als Kompromiss schlage ich vor, dass …  —  В качестве компромисса я предлагаю, чтобы …

5.8 Nachfragen und Gespräch beenden

  • Könnten Sie das bitte erklären?  —  Не могли бы Вы объяснить это?
  • Was meinen Sie genau mit …?  —  Что именно Вы имеете в виду под…?
  • Habe ich Sie richtig verstanden, dass …?  —  Правильно ли я Вас понял(а), что…?
  • Entschuldigung, könnten Sie das wiederholen?  —  Извините, не могли бы Вы повторить?
  • Ich denke, wir haben eine gute Lösung gefunden.  —  Думаю, мы нашли хорошее решение.
  • Das war ein konstruktives Gespräch.  —  Это был конструктивный разговор.
  • Ich bin mit diesem Ergebnis zufrieden.  —  Я доволен(льна) этим результатом.
  • Vielen Dank für das Gespräch.  —  Большое спасибо за разговор.
